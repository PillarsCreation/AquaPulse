## 一、项目简介

AquaPulse 智讯通是一套面向**全年四季水灾害**的 AI 地理智能体，以「测-报-预-救-评」五环节闭环为核心：

- **测**：接入气象雷达、卫星遥感、水文遥测、物联网传感器、社交舆情等多源异构数据；
- **报**：按国标自动生成红 / 橙 / 黄 / 蓝四级预警，同时产出**村民通俗版**与**专业溯源版**双版本文案；
- **预**：双推演引擎——夏秋季「**八步山洪模型链**」（降雨输入 → 产汇流 → 沟道演进 → 淹没分析 → 风险评估 → 分级预警 → 转移任务 → 反馈校正），冬春季「**凌汛推演引擎**」（冰情输入 → 热力评估 → 冰塞壅水 → 漫滩淹没 → 风险分级 → 转移任务）；
- **救**：AI 智能派单自动匹配救援队伍、规划绕开深水点路线、生成任务包直达救援终端；公网中断时自动切换**北斗短报文**，断网不断联；
- **评**：淹没水深 + 无人机正射影像 AI 识别受淹农田，定损周期从 7 天压缩到 2 天。
并且加入数字人形象，引导、汇报功能鲜活生动。
**设计原则**：AI 只做「翻译」与「编排」，绝不直接做数值计算——所有水文结果由确定性模型产出，每条处置建议均可回溯至官方应急预案原文，**防汛场景下模型不容许编造**。

## 二、一年四季灾害覆盖

传统防汛系统只盯夏汛，AquaPulse 把防护栏拉到全年 12 个月：

| 灾种 | 高发季节 | 模型链 | 核心推演参数 |
|------|---------|--------|-------------|
| 山洪 | 5–10 月 | 八步山洪模型链 | 雨强 / 累计降雨 / 预报降雨 / 地形坡度 |
| 滑坡 | 5–10 月 | 八步山洪模型链（伴生链） | 降雨渗透 + 坡度 + 危岩历史 |
| 城市内涝 | 6–9 月 | 内涝模型链（规划中） | 降雨 + 管网排放能力 + DEM 高程 |
| 台风风暴潮 | 7–9 月 | 台风模型链（规划中） | 风圈 + 暴雨 + 潮位顶托 |
| **凌汛** | **11–次年 3 月** | **凌汛推演引擎** | **冰厚 / 流凌密度 / 气温 / 水位超警** |
| 南方冬汛 | 11–次年 1 月 | 冬汛模型链（规划中） | 冬季持续降水 + 海温异常（厄尔尼诺）信号 |
| 融雪洪水 | 秋末冬初 / 初春 | 融雪模型链（规划中） | 气温骤升 + 积雪冰川储量 + 河道径流 |
| 冬春干旱 | 11–次年 4 月 | 水源调度模型链（规划中） | 降雨偏距 + 库容 + 需水预测 |

### 秋冬洪水并不缺席，只是「换了主角」

与夏季暴雨型洪水成因不同，我国秋冬季洪水主要有三种类型：

| 类型 | 高发时段 | 主要发生区域 | 成因机制 |
|------|---------|-------------|---------|
| **凌汛** | 封河期 11月—次年1月、开河期 2—3月 | 黄河宁夏—内蒙古段、下游山东段，黑龙江、松花江等北方河流 | 河道自低纬度流向高纬度，下游先封河、上游后解冻，冰凌在狭窄弯道处堆积形成冰塞或冰坝，壅高水位 |
| **南方冬汛** | 11月—次年1月，强厄尔尼诺年份更明显 | 湘江、赣江、桂江、贺江等南方河流 | 冬季持续性强降水，多与强厄尔尼诺背景下副热带高压异常、水汽输送异常有关 |
| **融雪型洪水** | 秋末冬初和初春 | 新疆、青藏高原等山区河流 | 气温骤升导致积雪、冰川加速融化汇入河道 |

**典型案例**：2008 年 3 月黄河鄂尔多斯杭锦旗段发生 40 年不遇特大凌汛，大堤溃口淹没 11 个村镇、万余人撤离，直接经济损失近 7 亿元；2015 年 11 月受强厄尔尼诺影响，湘江发生 1961 年有气象记录以来最大冬汛，桂江、贺江、赣江等 30 余条河流超警，55.5 万人受灾、直接经济损失约 9.9 亿元。2025—2026 年度黄河凌汛期受拉尼娜与全球变暖交织影响，防凌形势被评估为「更为复杂严峻」。

**防御要点**：凌汛依靠「上控、中分、下排」综合调度——龙羊峡、刘家峡、海勃湾、万家寨、小浪底等骨干水库联合调控，配合堤防、应急分洪区和「天空地」立体监测体系（卫星遥感 + 无人机 + 视频 + 人工巡测）；南方冬汛侧重水库拦洪错峰（如广西龙滩、湖南双牌）和及时转移受威胁群众。AquaPulse 的凌汛推演引擎以「冰厚 + 流凌密度 + 气温 + 水位超警」四要素推演开江时间与淹没范围，比传统人工会商提前 **6–12 小时**发出转移指令。

## 三、快速开始

### 方式 1：零依赖单文件演示（评委 / 用户）

```bash
git clone https://github.com/YOUR_ORG/AquaPulse.git
cd AquaPulse
# 双击打开即可，无需后端、无需联网、无任何 CDN 依赖
demo/aquapulse-standalone.html
```

### 方式 2：完整工程开发运行（开发者）

```bash
npm install
npm run dev        # 前端 Vite :5173 + 后端 Express :3001 同时启动
# 单独启动：npm run client:dev / npm run server:dev
npm run build      # 类型检查 + 生产构建 → dist/
npm run check      # 仅 TypeScript 类型检查
npm run lint       # ESLint
```

技术栈：React 18 + TypeScript + Vite 6 前端；Express + TypeScript + better-sqlite3 后端；Leaflet GIS；WebSocket 实时通信；Tailwind CSS；Docker / Vercel 部署。

### 方式 3：GitHub Pages 在线演示

仓库已内置 `.github/workflows/deploy-pages.yml`：推送 main 分支后自动构建并发布。仓库 Settings → Pages → Source 选择 **GitHub Actions** 即可。

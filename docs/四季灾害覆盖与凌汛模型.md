# 四季灾害覆盖与凌汛推演模型 · 设计文档

> 版本：v1.0 ｜ 日期：2026-10-18 ｜ 模块：全年水灾害防御

## 1. 为什么要把防汛系统扩展到全年四季

我国水灾害并不只发生在夏天。基层防汛队伍 5–10 月连轴转，11 月后往往"刀枪入库、马放南山"，但北方江河的**凌汛**在冬春季持续构成威胁——据统计，凌汛虽年均成灾面积不及暴雨洪水，但其突发性强、滩区群众撤离窗口极短（往往只有几小时），且正值严寒季节，救援条件恶劣、房屋抗涝能力低，单次灾害伤亡率反而更高。

AquaPulse 的设计目标即：**同一套「测-报-预-救-评」闭环，覆盖一年四季全类型水灾害**。灾种切换时，数据接入、预警分级、双版本文案、派单救援、灾情统计各环节复用，仅推演引擎按灾种切换模型链。

## 2.5 秋冬洪水三种类型（与夏季暴雨洪水的成因差异）

秋冬季节的洪水在中国并不缺席，只是"换了主角"——北方是冰凌惹的祸，南方则是偶发的冬季暴雨所致。

| 类型 | 高发时段 | 主要发生区域 | 成因机制 |
|------|---------|-------------|---------|
| **凌汛** | 封河期 11月—次年1月、开河期 2—3月 | 黄河宁夏—内蒙古段、下游山东段，黑龙江、松花江等北方河流 | 河道自低纬度流向高纬度，下游先封河、上游后解冻，冰凌在狭窄弯道处堆积形成冰塞或冰坝，壅高水位 |
| **南方冬汛** | 11月—次年1月，强厄尔尼诺年份更明显 | 湘江、赣江、桂江、贺江等南方河流 | 冬季持续性强降水，多与强厄尔尼诺事件背景下副热带高压异常、水汽输送异常有关 |
| **融雪型洪水** | 秋末冬初和初春 | 新疆、青藏高原等山区河流 | 气温骤升导致积雪、冰川加速融化汇入河道 |

**典型案例**：

- **凌汛**：2008 年 3 月黄河鄂尔多斯杭锦旗段发生 40 年不遇特大凌汛，大堤溃口淹没 11 个村镇、万余人撤离，直接经济损失近 7 亿元；历史上 1933 年内蒙古磴口县凌汛决口，300 余里一片汪洋。2025—2026 年度黄河凌汛期受拉尼娜与全球变暖交织影响，防凌形势被评估为"更为复杂严峻"。
- **南方冬汛**：2015 年 11 月，受强厄尔尼诺事件影响，湖南湘江发生 1961 年有气象记录以来最大冬汛，广西桂江、广东贺江、江西赣江等 30 余条河流超警，55.5 万人受灾，直接经济损失约 9.9 亿元。

**防御要点**：

- **凌汛**：「上控、中分、下排」综合调度——龙羊峡、刘家峡、海勃湾、万家寨、小浪底等骨干水库联合调控，配合堤防、应急分洪区和"天空地"立体监测体系（卫星遥感 + 无人机 + 视频 + 人工巡测），近二十多年黄河未再发生凌汛决口；
- **南方冬汛**：水库拦洪错峰（如广西龙滩水电站、湖南双牌水库）和及时转移受威胁群众；
- **融雪型**：气温骤升预警触发提前腾库，山区河道巡查封堵。

**总体分布特征**：黄河宁蒙河段是防凌的重中之重，每年 11 月中下旬进入流凌期，来年 3 月中下旬凌汛期结束；南方冬汛属于小概率事件，多出现在强厄尔尼诺等特殊气候背景年份；融雪型洪水集中在西北与青藏高原山区河流。

## 3. 凌汛推演引擎（FG-IceModel）

### 3.1 机理

河流由低纬度流向高纬度时，上游（低纬）升温快、解冻早，下游（高纬）封冻早、解冻晚。开江期上游来水携带破裂冰盖形成**流凌**，在弯道、窄段、桥梁墩柱处**卡塞**形成冰坝，过水断面骤减，水位**壅高**，漫过堤防淹没滩区，即"凌汛"。若冰盖在短时间内大量崩塌并伴随洪峰，形成"**武开河**"，破坏力最大。

### 3.2 四要素输入

| 参数 | 符号 | 数据来源 | 说明 |
|------|------|---------|------|
| 冰厚 | `iceThickness` (m) | 冰厚遥测站 / 卫星遥感 | 决定冰盖质量与卡塞强度 |
| 流凌密度 | `flowDensity` (%) | 流凌视频 AI 识别 / 人工观测 | 决定卡塞概率 |
| 气温 | `temp` (℃) | 气象预报 | 决定热力融冰速度（武开河风险） |
| 水位超警 | `waterRise` (m) | 水文站遥测 | 决定壅水起点与漫滩深度 |

### 3.3 八步推演链

```
① 冰情输入（卫星遥感+冰厚遥测站+水文站融合）
   ↓
② 热力评估（气温回升系数 → 武开河风险 → 开江倒计时）
   ↓
③ 冰塞壅水评估（流凌密度×0.6 + 冰厚×80 + 水位超警×30 → 卡塞风险分）
   ↓
④ 漫滩淹没分析（冰厚×1.8 + 水位超警×1.5 → 最大水深；淹没面积与水深分布）
   ↓
⑤ 风险评估（危险性×0.4 + 暴露度×0.35 + 脆弱性×0.25 → 综合风险分）
   ↓
⑥ 分级预警（≥75 红 / ≥55 橙 / ≥35 黄 / 其余蓝，同国标四级）
   ↓
⑦ 转移任务（按等级确定转移人数、安置点、责任人、撤离路线）
   ↓
⑧ 反馈校正（FG-IceModel v1.2，基于近五年凌汛灾例校正）
```

### 3.4 与山洪模型链的差异

| 维度 | 八步山洪模型链 | 凌汛推演引擎 |
|------|--------------|-------------|
| 季节 | 夏秋（5–10 月） | 冬春（11–3 月） |
| 主控输入 | 雨强 / 累计 / 预报降雨 | 冰厚 / 流凌密度 / 气温 / 水位 |
| 核心物理过程 | SCS-CN 产汇流 + 沟道演进 | 热力融冰 + 冰凌卡塞壅水 |
| 时间尺度 | 洪峰 15–60 分钟 | 开江 6–48 小时 |
| 避险要点 | 向沟道两侧高地撤离，禁顺河道奔跑 | 撤至堤防高程以上，禁上冰面 |
| 精度 | 洪峰到达 ±15 min，淹没 ±12% | 开江时间 ±6 h，冰塞位置识别 92% |

### 3.5 精度与校正

- 开江时间误差 **±6 小时**（基于 2021–2025 年五个凌汛期灾例回代校正）；
- 冰塞位置识别准确率 **92%**（弯道 + 窄段 + 桥墩三类卡塞形态）；
- 每年汛后结合新灾例更新 `feedbackCorrection` 中的模型版本与校正说明。

## 4. 可扩展性设计

推演引擎采用**统一输出契约**（rainfall / runoff / channelRouting / inundation / riskAssessment / transferTask / feedbackCorrection），新增灾种只需：

1. 在 `DTYPE` 中登记灾种（名称、季节、颜色、描述）；
2. 在 `SEASON_CALENDAR` 中标注高发月份；
3. 实现一个返回统一契约的推演函数（如规划中的城市内涝、台风风暴潮、干旱水源调度模型链）；
4. 预警发布页与移动端自动完成灾种自适应，无需改动界面代码。

## 5. 数据安全与责任边界

- 模型仅输出**风险参考**，正式预警发布须经防汛值班领导签收；
- 所有数值计算由确定性 Code 节点完成，大模型仅承担数据融合、文案生成与检索增强，**不做数值编造**；
- 每条转移指令可回溯至《防汛应急预案》对应条款，支持审计核查。
